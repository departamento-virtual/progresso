# Fase Contabilidade — Site institucional

Site estático desenvolvido em HTML5, CSS3 e JavaScript, pronto para publicação no GitHub Pages ou hospedagem tradicional.

## Arquivos
- `index.html` — página principal
- `styles.css` — estilos responsivos
- `script.js` — menu mobile e pequenos comportamentos
- `robots.txt` — instruções para mecanismos de busca
- `sitemap.xml` — sitemap básico

## Publicação no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie estes arquivos diretamente para a raiz do repositório.
3. Em **Settings → Pages**, selecione a branch principal e a pasta `/root`.
4. Publique.
5. Se utilizar domínio próprio, configure o domínio no GitHub Pages e ajuste o `canonical` e o `sitemap.xml` em `index.html`/`robots.txt`.

## Antes de publicar
- Confirme endereço, telefone, e-mail e demais dados cadastrais.
- Substitua `https://fasecontabilidade.com/` pelo domínio real se ele for diferente.
- Não publique depoimentos, avaliações, certificações ou promessas que não possam ser comprovados.
- O conteúdo do site identifica expressamente a empresa como privada e independente de órgãos governamentais.
